## Style Fusion

- If multiple compatible styles appear, fuse them through scene and wardrobe. Example: `/cyber /editorial` becomes a neon city fashion editorial.
- If styles conflict, preserve the last explicit style unless the user asks for a hybrid.
- Keep the core skin, facial structure, temperament, and safety controls even when style is strong.
