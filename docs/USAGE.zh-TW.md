## 1. 如何選擇

Generator 專注於清冷、克制、低飽和的室內女性寫真提示詞；Director 提供多風格分流、完整畫面設計、提示詞修復和參考圖任務。以下比較依據本 Repo 附帶的規則文件，不是實際生圖品質測試結果。

| 項目 | Generator | Director |
| --- | --- | --- |
| 預設審美 | 清冷私房或低飽和寫真 | 按意圖選擇路線，無法判斷時使用清純生活照 |
| 參數保護 | 鎖定明確填寫的安全值，只補全空白、缺失或 `自动` | 同樣鎖定，並檢查參數是否落實到最終提示詞 |
| 畫面構建 | 五官、氣質、身形、服裝、場景、姿態、鏡頭、光色 | 額外協調時間切片、小事件、視線、動作、衣料動態與空間層次 |
| 原生控制 | 17 個主要欄位，包含面部呈現與精修程度 | 增加配色關係、華麗度、平台用途、輸出模式與參考圖角色 |
| 預設輸出 | 五個區塊，一篇完整中文提示詞 | 四個區塊，模組解析與嚴格五段式最終提示詞 |
| 優化及診斷 | 未定義專用任務模組 | 有專用任務模組 |
| 圖片反推 | 未列為正式流程 | 有正式流程 |
| 直接生圖及編輯 | 規格明確列為範圍外 | 明確要求且環境有可用能力時執行 |
| 人物及商品參考 | 身份複製及圖片編輯屬於範圍外 | 支援本人或已授權成年人物與商品參考圖 |
| 操作複雜度 | 入口集中，範例按需讀取 | 模組更多，標準輸出更長 |

兩者都必須保留你指定的五官方向。例如「溫柔圓臉型＋清冷攝影風格」，不能擅自換成尖下巴。Generator 會擴寫細節，並非單純關鍵詞堆疊。Director 更強調讓這些細節形成同一個可拍攝瞬間，例如讀完一頁後停下、手指停在書頁邊、視線看向窗外，窗光同時服務表情與衣料。

主要製作清冷室內寫真、重視面部裁切和精修控制時，Generator 更直接。需要都市、古風、電商、運動、旅行、完整場景或修復流程時，選擇 Director。日常一次調用一個即可。如果把 Generator 初稿交給 Director，附上全部原始鎖定參數並要求保留審美，不要自動把 `清冷私房` 改稱 `纯欲曲线生活照`。

## 2. 安裝

需要 Git、支援本機檔案技能的 Codex 和 Repo 存取權。先在父層工作目錄執行 clone，再從同一目錄選擇 Windows PowerShell 或 macOS/Linux Bash 安裝區塊。複製的是兩個完整技能目錄，不是僅複製 `SKILL.md`。

安裝前檢查目標是否已存在。已有版本應先備份或有意識地合併；下面的命令會拒絕覆蓋。Repo 中的 `skills/` 是集合打包目錄，安裝後的調用名稱不變。

```powershell
git clone https://github.com/junhao-ye/Female-Portrait-Prompt-Skills.git
```

```powershell
$skillDestination = Join-Path $env:USERPROFILE '.codex\skills'
if ($env:CODEX_HOME) { $skillDestination = Join-Path $env:CODEX_HOME 'skills' }
foreach ($skillName in @('female-portrait-prompt-generator', 'female-portrait-director')) {
    if (Test-Path -LiteralPath (Join-Path $skillDestination $skillName)) {
        throw "Existing skill: $skillName. Back up or reconcile it before installing."
    }
}
New-Item -ItemType Directory -Path $skillDestination -Force | Out-Null
Copy-Item -LiteralPath '.\Female-Portrait-Prompt-Skills\skills\female-portrait-prompt-generator' -Destination $skillDestination -Recurse -ErrorAction Stop
Copy-Item -LiteralPath '.\Female-Portrait-Prompt-Skills\skills\female-portrait-director' -Destination $skillDestination -Recurse -ErrorAction Stop
```

```bash
skill_destination="${CODEX_HOME:-$HOME/.codex}/skills"
for skill_name in female-portrait-prompt-generator female-portrait-director; do
  if [ -e "$skill_destination/$skill_name" ]; then
    printf 'Existing skill: %s. Back up or reconcile it before installing.\n' "$skill_name" >&2
    exit 1
  fi
done
mkdir -p "$skill_destination"
cp -R Female-Portrait-Prompt-Skills/skills/female-portrait-prompt-generator "$skill_destination/"
cp -R Female-Portrait-Prompt-Skills/skills/female-portrait-director "$skill_destination/"
```

安裝後開啟新的 Codex 對話，透過 `$female-portrait-prompt-generator` 或 `$female-portrait-director` 調用，也可在支援的介面中選擇技能。找不到技能時，檢查每個安裝目錄下是否直接包含 `SKILL.md`。Generator 寫提示詞不需要外部生圖服務；Director 的圖片任務需要環境提供圖片生成或編輯能力。

## 3. 參數與預設值

範例使用來源檔案正式定義的中文欄位名稱和模式值，方便穩定重用；補充說明可使用中文、日文或英文。本手冊不新增翻譯別名。只填部分欄位也可以。

Generator 的 17 個主要欄位是：`写真风格`、`五官方向`、`场景方向`、`服装方向`、`服装颜色`、`气质标签`、`身形方向`、`线条强调`、`身体线条重点`、`姿态方向`、`镜头方向`、`面部呈现`、`光线方向`、`色调方向`、`精修程度`、`画幅比例`、`画质方向`。

僅空白、缺失或恰好為 `自动` 的值可自動匹配。預設傾向清冷室內、約 22–28 歲成年東亞女性、窗光、克制服裝和配色、自然膚質、中等線條強調及 9:16。年齡重要時直接填寫明確成年年齡。

Director 增加或細分了 `配色方向`、`华丽度`、`年龄特征`、`身形吸引力强度`、`线条重点`、`光线氛围`、`滤镜效果`、`尺寸参数`、`平台用途`、`输出模式`、`补充要求` 及參考圖欄位。華麗度應落實為材質、刺繡、配飾、服裝層次和背景裝飾，而不是只增加「華麗」形容詞。

| Generator 欄位 | 遷移到 Director | 需要保留 |
| --- | --- | --- |
| `写真风格` | `写真风格` | 風格並非全部一一對應 |
| `五官方向`、`场景方向`、`气质标签`、`身形方向`、`镜头方向`、`画幅比例` | 同名欄位 | 原始明確值 |
| `服装方向`＋`服装颜色` | `服装方向`，必要時加 `配色方向` | 在服裝描述裡保留服裝顏色 |
| `线条强调` | `身形吸引力强度` | 意義接近，不保證量表完全相同 |
| `身体线条重点` | `线条重点` | 具體區域 |
| `姿态方向`、`面部呈现` | 保留原欄位，或明確放入 `补充要求` | 姿態與臉部可見範圍 |
| `光线方向` | `光线氛围` | 光源與方向 |
| `色调方向` | `滤镜效果`，必要時補配色 | 區分後製調色與物件顏色 |
| `精修程度`、`画质方向` | 明寫在 `补充要求` 或相關視覺欄位 | 膚質與完成度要求 |

Director 預設畫幅 9:16；未指定像素時不能虛構尺寸。畫幅與使用者填寫的尺寸應放入最終提示詞第一句。實際可輸出尺寸仍由生圖工具的設定決定。

## 4. Director 的風格、氣質與任務

目前有 14 條已實作主風格路線：

| 類別 | 正式風格值 |
| --- | --- |
| 生活 | `清纯生活照`、`复古港风写真`、`法式慵懒写真`、`旅行假日写真` |
| 時尚 | `都市时尚写真`、`活力运动写真`、`影楼精修写真` |
| 曲線 | `纯欲曲线生活照`、`东方丰腴写真` |
| 東方與幻想 | `新中式东方写真`、`古风仙侠美人图`、`清冷仙气古风增强版`、`明媚华贵古风增强版` |
| 商業 | `电商服装模特图` |

每張圖或每個版本只選一個主路線。7 個氣質增強模組分別為明艷女主、清冷女主、冷艷御姐、溫柔姐姐、知性、輕熟都市和甜酷；它們只調整表情、視線、姿態、妝容和細節，不得覆蓋主風格或鎖定參數。需要比較風格時，要求獨立版本，而不是在一張圖裡混合所有路線。

6 個任務模組分別負責提示詞優化、失敗診斷、參數推薦、安全改寫、圖片反推與參考圖保留直接生成。複合任務可以順序處理，例如先診斷再優化。它們是操作指引檔案，不是獨立 API 或內建生圖引擎。

註冊表中的日系清透、珠寶廣告等規劃占位不等於已實作的獨立路線。可以描述這些視覺需求並使用現有路線，但不能宣稱已載入不存在的模組。

## 5. 輸出模式

Generator 預設嚴格包含五部分：`参数锁定复核`、`完整生成提示词`、`本次自动补全部分`、`主要吸睛点`、`负面限制词`。複核中應列出明確參數、自動值、衝突調和及成年非露骨範圍；吸睛點為 3–5 個。它沒有正式定義 Director 的模式選擇器。

| Director 的 `输出模式` | 結果 |
| --- | --- |
| `标准` | 預設：參數鎖定、可讀模組解析、最終提示詞、負面約束 |
| `简洁` | 只返回最終提示詞與負面約束 |
| `导演详版` | 在標準模式上進一步說明場景與攝影設計 |
| `直接生成图片` | 內部準備提示詞，再調用可用的圖片能力 |
| `参考图直接生成` | 鎖定上傳主體後生成或編輯，返回圖片和簡短說明 |

標準模式的最終提示詞固定五個實質段落：第一段寫尺寸、人物、成年年齡、五官、妝容、氣質；第二段寫時間切片、小事件、動作與視線；第三段寫身形、服裝、配色、材質、配飾與華麗度；第四段寫環境、空間、鏡頭、構圖與景深；第五段寫光位、高光、陰影、調色與質感。公開解析展示視覺決策與效果，不公開內部逐步推理。

最終提示詞與負面約束分別置於獨立的 Markdown `text` 程式碼區塊。`只要最终提示词` 會選擇簡潔輸出，仍包含負面約束。僅提供參數區塊永遠表示寫提示詞；希望出圖時必須明確說生成圖片。直接生圖模式可不展示內部提示詞。

## 6. 可複製範例

這些是可貼入 Codex 的請求，不代表已經生成圖片。方括號占位內容應替換為你的輸入。人物必須明確成年；純文字預設使用虛構人物。

### A. Generator：完整室內寫真控制

```text
$female-portrait-prompt-generator

人物为虚构的 26 岁成年东亚女性。未填字段自动补全，已填参数保持不变。
写真风格：清冷私房
五官方向：温柔圆脸型
场景方向：窗边
服装方向：白衬衫
服装颜色：米白
气质标签：安静、克制
身形方向：柔和曲线
线条强调：中
身体线条重点：锁骨肩颈
姿态方向：低头安静
镜头方向：半身近景
面部呈现：完整脸部
光线方向：阴天窗光
色调方向：冷灰蓝
精修程度：自然真实
画幅比例：3:4
画质方向：真实摄影
```

預期返回五個規定區塊，保留溫柔圓臉、米白襯衫、完整臉部、自然膚質與 3:4。缺失細節可以補充，不能藉補全替換這些選擇。

### B. Director：完整都市場景

```text
$female-portrait-director

写真风格：都市时尚写真
年龄特征：28 岁成年东方女性
五官方向：知性长脸型
场景方向：雨后城市街角的咖啡馆外
服装方向：深灰色西装外套、米白色内搭、黑色直筒长裤
配色方向：深灰为主，米白为辅，少量银色点缀
华丽度：低，依靠面料与剪裁体现质感
气质标签：知性、冷静、轻熟
身形方向：自然协调
身形吸引力强度：弱
线条重点：肩颈与整体比例
镜头方向：平视，膝盖以上构图
光线氛围：阴天柔光，少量街边暖光
滤镜效果：低饱和，保留自然肤色
```

預期為標準輸出、五段式融合提示詞與獨立負面約束。停步、視線、衣料、光線和雨後環境應屬於同一張可信的照片。

## 7. 參考圖流程

把每張圖片標記為 `identity_reference`（本人或授權成年人物）、`product_reference`（服裝或商品）、`style_reference`（僅參考風格）或 `edit_target`（待編輯原圖）。角色不明確時，先釐清再生成。

人物預設鎖定可觀察的臉型、眉眼、鼻唇與可辨識度，不自動鎖定髮型、身形、姿態、妝容和構圖。商品預設鎖定品類、輪廓、顏色、材質、圖案及關鍵結構。需要更嚴格保留時，在 `保留对象` 與 `禁止改变` 中明確增加要求。

風格圖不代表有權或要求複製其中人物。圖片反推返回文字，參考圖生成返回圖片。Director 要求檢查人物或商品漂移，適當時可進行一次定向重試。Logo、小字和複雜圖案不保證準確；精確文字可能需要後續編輯或合成。

## 8. 故障排查與已知不一致

| 現象 | 處理方式 |
| --- | --- |
| 五官、服裝或顏色被替換 | 提供原始鎖定值，去除衝突預設詞，要求診斷修復 |
| 輸出太長 | Director 明確選 `简洁`；Generator 另行要求較短輸出 |
| 參數區塊只返回文字 | 屬於預期；要圖片時明確選擇 `直接生成图片` |
| 參考身份漂移 | 確認角色和保護特徵，簡化修改，評估模型限制 |
| 畫幅或像素不符 | 同時檢查最終提示詞與生圖工具設定 |
| 技能無法載入 | 檢查完整目錄和入口位置，開啟新對話 |

來源文件的以下問題原樣保留，沒有靜默修復：

1. Director 核心流程預設成年年齡為 20–28，參數表為 24–28；Generator 預設約 22–28。建議明確填寫年齡。
2. Director 部分舊範例仍是三段或舊模板，但目前入口要求標準模式嚴格五段。執行以目前入口和核心流程為準。
