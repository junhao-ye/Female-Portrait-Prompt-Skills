## 1. 如何选择

Generator 专注于清冷、克制、低饱和的室内女性写真提示词；Director 提供多风格分流、完整画面设计、提示词修复和参考图任务。以下比较依据本仓库附带的规则文件，不是实际生图质量测试结果。

| 项目 | Generator | Director |
| --- | --- | --- |
| 默认审美 | 清冷私房或低饱和写真 | 按意图选择路线，无法判断时使用清纯生活照 |
| 参数保护 | 锁定明确填写的安全值，只补全空白、缺失或 `自动` | 同样锁定，并检查参数是否落实到最终提示词 |
| 画面构建 | 五官、气质、身形、服装、场景、姿态、镜头、光色 | 额外协调时间切片、小事件、视线、动作、衣料动态与空间层次 |
| 原生控制 | 17 个主要字段，包含面部呈现与精修程度 | 增加配色关系、华丽度、平台用途、输出模式与参考图角色 |
| 默认输出 | 五个区块，一篇完整中文提示词 | 四个区块，模块解析与严格五段式最终提示词 |
| 优化及诊断 | 未定义专用任务模块 | 有专用任务模块 |
| 图片反推 | 未列为正式流程 | 有正式流程 |
| 直接生图及编辑 | 规格明确列为范围外 | 明确要求且环境有可用能力时执行 |
| 人物及商品参考 | 身份复制及图片编辑属于范围外 | 支持本人或已授权成年人物与商品参考图 |
| 操作复杂度 | 入口集中，示例按需读取 | 模块更多，标准输出更长 |

两者都必须保留你指定的五官方向。例如“温柔圆脸型＋清冷摄影风格”，不能擅自换成尖下巴。Generator 会扩写细节，并非单纯关键词堆叠。Director 更强调让这些细节形成同一个可拍摄瞬间，例如读完一页后停下、手指停在书页边、视线看向窗外，窗光同时服务表情与衣料。

主要制作清冷室内写真、重视面部裁切和精修控制时，Generator 更直接。需要都市、古风、电商、运动、旅行、完整场景或修复流程时，选择 Director。日常一次调用一个即可。如果把 Generator 初稿交给 Director，附上全部原始锁定参数并要求保留审美，不要自动把 `清冷私房` 改称 `纯欲曲线生活照`。

## 2. 安装

需要 Git、支持本地文件技能的 Codex 和仓库访问权限。先在父级工作目录执行 clone，再从同一目录选择 Windows PowerShell 或 macOS/Linux Bash 安装块。复制的是两个完整技能目录，不是仅复制 `SKILL.md`。

安装前检查目标是否已存在。已有版本应先备份或有意识地合并；下面的命令会拒绝覆盖。仓库中的 `skills/` 是集合打包目录，安装后的调用名称不变。

```powershell
git clone https://github.com/junhao-ye/Female-Portrait-Prompt-Skills.git
```

```powershell
$skillDestination = Join-Path $env:USERPROFILE '.codex\skills'
if ($env:CODEX_HOME) { $skillDestination = Join-Path $env:CODEX_HOME 'skills' }
foreach ($skillName in @('female-portrait-prompt-generator', 'female-portrait-director')) {
    if (Test-Path -LiteralPath (Join-Path $skillDestination $skillName)) {
        throw "Existing skill: $skillName. Back up or reconcile it before installing."
    }
}
New-Item -ItemType Directory -Path $skillDestination -Force | Out-Null
Copy-Item -LiteralPath '.\Female-Portrait-Prompt-Skills\skills\female-portrait-prompt-generator' -Destination $skillDestination -Recurse -ErrorAction Stop
Copy-Item -LiteralPath '.\Female-Portrait-Prompt-Skills\skills\female-portrait-director' -Destination $skillDestination -Recurse -ErrorAction Stop
```

```bash
skill_destination="${CODEX_HOME:-$HOME/.codex}/skills"
for skill_name in female-portrait-prompt-generator female-portrait-director; do
  if [ -e "$skill_destination/$skill_name" ]; then
    printf 'Existing skill: %s. Back up or reconcile it before installing.\n' "$skill_name" >&2
    exit 1
  fi
done
mkdir -p "$skill_destination"
cp -R Female-Portrait-Prompt-Skills/skills/female-portrait-prompt-generator "$skill_destination/"
cp -R Female-Portrait-Prompt-Skills/skills/female-portrait-director "$skill_destination/"
```

安装后打开新的 Codex 对话，通过 `$female-portrait-prompt-generator` 或 `$female-portrait-director` 调用，也可在支持的界面中选择技能。找不到技能时，检查每个安装目录下是否直接包含 `SKILL.md`。Generator 写提示词不需要外部生图服务；Director 的图片任务需要环境提供图片生成或编辑能力。

## 3. 参数与默认值

示例使用源文件正式定义的中文字段名和模式值，方便稳定复用；补充说明可使用中文、日文或英文。本手册不新增翻译别名。只填部分字段也可以。

Generator 的 17 个主要字段是：`写真风格`、`五官方向`、`场景方向`、`服装方向`、`服装颜色`、`气质标签`、`身形方向`、`线条强调`、`身体线条重点`、`姿态方向`、`镜头方向`、`面部呈现`、`光线方向`、`色调方向`、`精修程度`、`画幅比例`、`画质方向`。

仅空白、缺失或恰好为 `自动` 的值可自动匹配。默认倾向清冷室内、约 22–28 岁成年东亚女性、窗光、克制服装和配色、自然肤质、中等线条强调及 9:16。年龄重要时直接填写明确成年年龄。

Director 增加或细分了 `配色方向`、`华丽度`、`年龄特征`、`身形吸引力强度`、`线条重点`、`光线氛围`、`滤镜效果`、`尺寸参数`、`平台用途`、`输出模式`、`补充要求` 及参考图字段。华丽度应落实为材质、刺绣、配饰、服装层次和背景装饰，而不是只增加“华丽”形容词。

| Generator 字段 | 迁移到 Director | 需要保留 |
| --- | --- | --- |
| `写真风格` | `写真风格` | 风格并非全部一一对应 |
| `五官方向`、`场景方向`、`气质标签`、`身形方向`、`镜头方向`、`画幅比例` | 同名字段 | 原始明确值 |
| `服装方向`＋`服装颜色` | `服装方向`，必要时加 `配色方向` | 在服装描述里保留服装颜色 |
| `线条强调` | `身形吸引力强度` | 意义接近，不保证量表完全相同 |
| `身体线条重点` | `线条重点` | 具体区域 |
| `姿态方向`、`面部呈现` | 保留原字段，或明确放入 `补充要求` | 姿态与脸部可见范围 |
| `光线方向` | `光线氛围` | 光源与方向 |
| `色调方向` | `滤镜效果`，必要时补配色 | 区分后期调色与物体颜色 |
| `精修程度`、`画质方向` | 明写在 `补充要求` 或相关视觉字段 | 肤质与完成度要求 |

Director 默认画幅 9:16；未指定像素时不能虚构尺寸。画幅与用户填写的尺寸应放入最终提示词第一句。实际可输出尺寸仍由生图工具的设置决定。

## 4. Director 的风格、气质与任务

目前有 14 条已实现主风格路线：

| 类别 | 正式风格值 |
| --- | --- |
| 生活 | `清纯生活照`、`复古港风写真`、`法式慵懒写真`、`旅行假日写真` |
| 时尚 | `都市时尚写真`、`活力运动写真`、`影楼精修写真` |
| 曲线 | `纯欲曲线生活照`、`东方丰腴写真` |
| 东方与幻想 | `新中式东方写真`、`古风仙侠美人图`、`清冷仙气古风增强版`、`明媚华贵古风增强版` |
| 商业 | `电商服装模特图` |

每张图或每个版本只选一个主路线。7 个气质增强模块分别为明艳女主、清冷女主、冷艳御姐、温柔姐姐、知性、轻熟都市和甜酷；它们只调整表情、视线、姿态、妆容和细节，不得覆盖主风格或锁定参数。需要比较风格时，要求独立版本，而不是在一张图里混合所有路线。

6 个任务模块分别负责提示词优化、失败诊断、参数推荐、安全改写、图片反推与参考图保留直接生成。复合任务可以顺序处理，例如先诊断再优化。它们是操作指引文件，不是独立 API 或内置生图引擎。

注册表中的日系清透、珠宝广告等规划占位不等于已实现的独立路线。可以描述这些视觉需求并使用现有路线，但不能宣称已加载不存在的模块。

## 5. 输出模式

Generator 默认严格包含五部分：`参数锁定复核`、`完整生成提示词`、`本次自动补全部分`、`主要吸睛点`、`负面限制词`。复核中应列出明确参数、自动值、冲突调和及成年非露骨范围；吸睛点为 3–5 个。它没有正式定义 Director 的模式选择器。

| Director 的 `输出模式` | 结果 |
| --- | --- |
| `标准` | 默认：参数锁定、可读模块解析、最终提示词、负面约束 |
| `简洁` | 只返回最终提示词与负面约束 |
| `导演详版` | 在标准模式上进一步说明场景与摄影设计 |
| `直接生成图片` | 内部准备提示词，再调用可用的图片能力 |
| `参考图直接生成` | 锁定上传主体后生成或编辑，返回图片和简短说明 |

标准模式的最终提示词固定五个实质段落：第一段写尺寸、人物、成年年龄、五官、妆容、气质；第二段写时间切片、小事件、动作与视线；第三段写身形、服装、配色、材质、配饰与华丽度；第四段写环境、空间、镜头、构图与景深；第五段写光位、高光、阴影、调色与质感。公开解析展示视觉决策与效果，不公开内部逐步推理。

最终提示词与负面约束分别置于独立的 Markdown `text` 代码块。`只要最终提示词` 会选择简洁输出，仍包含负面约束。仅提供参数块永远表示写提示词；希望出图时必须明确说生成图片。直接生图模式可不展示内部提示词。

## 6. 可复制示例

这些是可贴入 Codex 的请求，不代表已经生成图片。方括号占位内容应替换为你的输入。人物必须明确成年；纯文字默认使用虚构人物。

```text

写真风格：清冷私房

线条强调：中
身体线条重点：锁骨肩颈
姿态方向：低头安静
镜头方向：半身近景
面部呈现：完整脸部

色调方向：冷灰蓝
精修程度：自然真实
画幅比例：3:4
画质方向：真实摄影
```

预期返回五个规定区块，保留温柔圆脸、米白衬衫、完整脸部、自然肤质与 3:4。缺失细节可以补充，不能借补全替换这些选择。

## 7. 参考图流程

把每张图片标记为 `identity_reference`（本人或授权成年人物）、`product_reference`（服装或商品）、`style_reference`（仅参考风格）或 `edit_target`（待编辑原图）。角色不明确时，先澄清再生成。

人物默认锁定可观察的脸型、眉眼、鼻唇与可辨识度，不自动锁定发型、身形、姿态、妆容和构图。商品默认锁定品类、轮廓、颜色、材质、图案及关键结构。需要更严格保留时，在 `保留对象` 与 `禁止改变` 中明确增加要求。

风格图不代表有权或要求复制其中人物。图片反推返回文字，参考图生成返回图片。Director 要求检查人物或商品漂移，适当时可进行一次定向重试。Logo、小字和复杂图案不保证准确；精确文字可能需要后续编辑或合成。

## 8. 故障排查与已知不一致

| 现象 | 处理方式 |
| --- | --- |
| 五官、服装或颜色被替换 | 提供原始锁定值，去除冲突默认词，要求诊断修复 |
| 输出太长 | Director 明确选 `简洁`；Generator 另行要求较短输出 |
| 参数块只返回文字 | 属于预期；要图片时明确选择 `直接生成图片` |
| 参考身份漂移 | 确认角色和保护特征，简化修改，评估模型限制 |
| 画幅或像素不符 | 同时检查最终提示词与生图工具设置 |
| 技能无法加载 | 检查完整目录和入口位置，打开新对话 |

来源文档的以下问题原样保留，没有静默修复：

1. Director 核心流程默认成年年龄为 20–28，参数表为 24–28；Generator 默认约 22–28。建议明确填写年龄。
2. Director 部分旧示例仍是三段或旧模板，但当前入口要求标准模式严格五段。执行以当前入口和核心流程为准。
3. Generator 的克制私房氛围、局部裁切，不等同于 Director 的 `pure-desire-curve` 路线；后者强调生活照构图，限制私房化及身体部位特写。按实际目标选择，不要只改名称。
4. Generator 的负面词带有清冷克制审美倾向，包括避免强闪光、高饱和网红风、文字和 Logo；不要原样搬到有冲突的商业或时尚任务中。

参数锁定是流程义务，不是像素、跨图身份或服装完全一致的保证。集合未做生图 A/B 测试。更长规则和模块可能增加读取与输出成本，但没有进行速度基准测试。
