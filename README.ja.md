# Female Portrait Prompt Skills

[English](README.md) | [简体中文](README.zh-CN.md) | [繁體中文](README.zh-TW.md) | [日本語](README.ja.md)

明確に成人である女性のポートレート向け Codex スキルをまとめたリポジトリです。特定の写真表現に向くプロンプト生成スキルと、幅広い撮影演出を扱うスキルを収録し、日本語・英語・簡体字中国語・繁体字中国語の README と詳しい利用ガイドを用意しています。

| スキル | 適した用途 | 標準出力 |
| --- | --- | --- |
| [female-portrait-prompt-generator](skills/female-portrait-prompt-generator/SKILL.md) | クールで控えめな低彩度の室内写真、指定パラメータの保持 | 完成プロンプト、パラメータ確認、補完項目、見どころ、ネガティブ指定 |
| [female-portrait-director](skills/female-portrait-director/SKILL.md) | 多様なスタイル、場面演出、最適化、診断、許可された参照画像 | 詳細なプロンプト。画像生成は明示的に依頼した場合のみ |

## クイックスタート

[インストール手順](docs/USAGE.ja.md#installation)に従ってスキルを配置し、新しい Codex 会話でどちらかを呼び出します。

```text
$female-portrait-prompt-generator
写真风格：清冷私房
五官方向：温柔圆脸型
场景方向：窗边
服装方向：米白色白衬衫
画幅比例：3:4
```

```text
$female-portrait-director
风格：都市时尚写真
场景：雨后咖啡馆外
服装：深灰西装与米白内搭
气质：知性、安静
画幅：3:4
输出模式：简洁
```

例では未定義の別名を避けるため、正式な中国語のフィールド名とモード値を維持しています。補足指示は日本語でも記述できます。未指定項目は補完され、安全な明示指定は保持されます。パラメータだけを渡した場合は、画像ではなくテキストを要求したものとして扱います。

## 対応範囲と制限

Generator はテキスト専用です。Director には実装済みの 14 スタイル、7 気質モジュール、6 タスクモジュールがあります。画像生成には実行環境側の機能が必要で、どちらも画像モデルを内蔵していません。同一人物の再現、商品細部、文字、ピクセル寸法はプロンプトだけでは保証できません。明確に成人である人物と各スキルの非露骨な表現範囲に従い、本人性を保持する参照画像は本人または使用許可のある成人のものを使います。

`python scripts/validate.py` で元ファイルの同一性、スキルの入口、各モジュール、多言語文書、例の構造、コレクション文書の相対リンクを確認できます。画像生成の品質テストは行いません。[貢献手順](CONTRIBUTING.md)を参照してください。
