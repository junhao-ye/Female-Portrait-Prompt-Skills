## 1. スキルの選び方

Generator はクールで控えめな低彩度の室内ポートレート用プロンプトに特化しています。Director は多様なスタイルの選択、場面演出、プロンプト修正、参照画像の処理を扱います。この比較は収録文書の仕様に基づくもので、画像品質の実測比較ではありません。

| 項目 | Generator | Director |
| --- | --- | --- |
| 標準の表現 | クールなプライベート室内写真、低彩度写真 | 意図に応じたルート。不明な場合は清潔な日常写真 |
| 指定の保持 | 安全な明示指定を固定し、空欄・未指定・`自动` だけを補完 | 明示指定を固定し、最終プロンプトへの反映も確認 |
| 画面の構築 | 顔、気質、体型、服装、場面、姿勢、カメラ、光と色 | 時間、ささやかな出来事、視線、動作、布の動き、空間の層も統合 |
| 主な入力 | 顔の見せ方、レタッチを含む 17 項目 | 配色関係、装飾密度、用途、出力モード、参照画像の役割も指定 |
| 標準出力 | 5 セクションと完成した中国語プロンプト | 4 セクションと厳密に 5 段落の最終プロンプト |
| 最適化・診断 | 専用タスクモジュールなし | 専用モジュールあり |
| 画像からのプロンプト化 | 正式な対応範囲外 | 対応フローあり |
| 直接生成・編集 | 仕様で明確に対象外 | 明示的な依頼と実行環境の機能がある場合に実施 |
| 人物・商品参照 | 本人性の複製と画像編集は対象外 | 本人または許可された成人と商品を参照可能 |
| 複雑さ | 集約された入口、必要な場合のみ例を読む | モジュールが多く、標準出力も長い |

両者とも指定された顔立ちを保持します。「優しい丸顔」とクールな写真表現を組み合わせても、都合よく尖った顎に変更してはいけません。Generator も詳細を展開するので、単なるキーワード集ではありません。Director は読書を一瞬止める、指をページに置く、窓の外を見る、といった動作と光を一枚の撮影可能な場面にまとめる点を重視します。

室内のクールな表現や顔のトリミング、仕上げの指定には Generator が扱いやすく、都市、歴史ファンタジー、商品、スポーツ、旅行、複雑な場面、修正作業には Director が向いています。通常は一度に一つを呼び出します。Generator の草稿を Director に渡す場合は、元の固定項目をすべて添えて表現の維持を依頼してください。`清冷私房` と `纯欲曲线生活照` を自動的に同義語として置き換えないでください。

## 2. インストール

Git、ローカルファイルのスキルに対応する Codex、本リポジトリへのアクセスが必要です。親となる作業ディレクトリで clone を実行し、同じ場所から Windows 用 PowerShell または macOS/Linux 用 Bash のどちらかを実行します。`SKILL.md` だけでなく、各スキルの完全なディレクトリをコピーします。

コピー前に既存のインストールを確認してください。既存版はバックアップするか、意図的に統合します。以下の例は既存ディレクトリがあれば停止します。リポジトリ内の `skills/` は配布用の構造であり、呼び出し名は変わりません。

```powershell
git clone https://github.com/junhao-ye/Female-Portrait-Prompt-Skills.git
```

```powershell
$skillDestination = Join-Path $env:USERPROFILE '.codex\skills'
if ($env:CODEX_HOME) { $skillDestination = Join-Path $env:CODEX_HOME 'skills' }
foreach ($skillName in @('female-portrait-prompt-generator', 'female-portrait-director')) {
    if (Test-Path -LiteralPath (Join-Path $skillDestination $skillName)) {
        throw "Existing skill: $skillName. Back up or reconcile it before installing."
    }
}
New-Item -ItemType Directory -Path $skillDestination -Force | Out-Null
Copy-Item -LiteralPath '.\Female-Portrait-Prompt-Skills\skills\female-portrait-prompt-generator' -Destination $skillDestination -Recurse -ErrorAction Stop
Copy-Item -LiteralPath '.\Female-Portrait-Prompt-Skills\skills\female-portrait-director' -Destination $skillDestination -Recurse -ErrorAction Stop
```

```bash
skill_destination="${CODEX_HOME:-$HOME/.codex}/skills"
for skill_name in female-portrait-prompt-generator female-portrait-director; do
  if [ -e "$skill_destination/$skill_name" ]; then
    printf 'Existing skill: %s. Back up or reconcile it before installing.\n' "$skill_name" >&2
    exit 1
  fi
done
mkdir -p "$skill_destination"
cp -R Female-Portrait-Prompt-Skills/skills/female-portrait-prompt-generator "$skill_destination/"
cp -R Female-Portrait-Prompt-Skills/skills/female-portrait-director "$skill_destination/"
```

配置後に新しい Codex 会話を開始し、`$female-portrait-prompt-generator` または `$female-portrait-director` を指定します。対応 UI ではスキル選択も利用できます。認識されない場合は、各インストール先の直下に `SKILL.md` があることを確認してください。Generator のテキスト出力には外部画像サービスは不要ですが、Director の画像処理には実行環境の生成・編集機能が必要です。

## 3. パラメータと標準値

例は再現しやすいように正式な中国語のフィールド名とモード値を維持しています。補足は日本語でも書けます。本ガイドは新しい翻訳別名を定義しません。一部の項目だけでも利用できます。

Generator の 17 項目は `写真风格`、`五官方向`、`场景方向`、`服装方向`、`服装颜色`、`气质标签`、`身形方向`、`线条强调`、`身体线条重点`、`姿态方向`、`镜头方向`、`面部呈现`、`光线方向`、`色调方向`、`精修程度`、`画幅比例`、`画质方向` です。

空欄・未指定・正確に `自动` と指定した値だけが自動補完の対象です。標準はクールな室内、約 22–28 歳の成人の東アジア女性、窓光、控えめな衣服と色、自然な肌、中程度のライン強調、9:16 です。年齢が重要なら明確な成人年齢を指定します。

Director は `配色方向`、`华丽度`、`年龄特征`、`身形吸引力强度`、`线条重点`、`光线氛围`、`滤镜效果`、`尺寸参数`、`平台用途`、`输出模式`、`补充要求` と参照画像項目も扱います。`华丽度` は豪華という形容詞だけではなく、素材、刺繍、装身具、重ね着、背景装飾の見え方として具体化します。

| Generator の項目 | Director への移行先 | 維持する内容 |
| --- | --- | --- |
| `写真风格` | `写真风格` | すべてが一対一対応ではない |
| `五官方向`、`场景方向`、`气质标签`、`身形方向`、`镜头方向`、`画幅比例` | 同名項目 | 元の明示指定 |
| `服装方向`＋`服装颜色` | `服装方向`、必要なら `配色方向` | 服自体の色も服装説明に残す |
| `线条强调` | `身形吸引力强度` | 意図は近いが同一尺度とは限らない |
| `身体线条重点` | `线条重点` | 対象となる具体的な部分 |
| `姿态方向`、`面部呈现` | 元の項目を残すか `补充要求` に明記 | 姿勢と顔の可視範囲 |
| `光线方向` | `光线氛围` | 光源と方向 |
| `色调方向` | `滤镜效果`、必要なら配色 | 調色と物体の色を区別 |
| `精修程度`、`画质方向` | `补充要求` または該当する視覚項目 | 肌と仕上げの指定 |

Director の標準比率は 9:16 です。未指定のピクセル寸法は作りません。比率と指定された寸法は最終プロンプトの最初の文に入れます。ただし実際の出力可能サイズは画像ツール側の設定に依存します。

## 4. Director のスタイル・気質・タスク

実装済みの主スタイルは 14 種類です。

| 分類 | 正式なスタイル値 |
| --- | --- |
| 日常 | `清纯生活照`、`复古港风写真`、`法式慵懒写真`、`旅行假日写真` |
| ファッション | `都市时尚写真`、`活力运动写真`、`影楼精修写真` |
| 曲線表現 | `纯欲曲线生活照`、`东方丰腴写真` |
| 東洋・ファンタジー | `新中式东方写真`、`古风仙侠美人图`、`清冷仙气古风增强版`、`明媚华贵古风增强版` |
| 商用 | `电商服装模特图` |

一枚または一バージョンにつき主ルートを一つ選びます。気質モジュールは華やかなヒロイン、クールなヒロイン、冷艶な大人、優しいお姉さん、知性、都会的な大人、スイートクールの 7 種類です。表情、視線、姿勢、メイク、細部を調整し、主スタイルや固定指定を上書きしません。比較する場合は別バージョンを依頼します。

6 タスクモジュールはプロンプト最適化、失敗診断、パラメータ提案、安全な書き換え、画像からのプロンプト化、参照保持による直接生成です。「診断後に最適化」のように順次使えます。これらは手順を定めた文書であり、独立 API や内蔵画像エンジンではありません。

レジストリにある日本風の透明感やジュエリー広告などの予定項目は、実装済み専用ルートではありません。既存ルートに視覚的な要望を加えることはできますが、存在しないモジュールを読み込んだと扱ってはいけません。

## 5. 出力モード

Generator は標準で `参数锁定复核`、`完整生成提示词`、`本次自动补全部分`、`主要吸睛点`、`负面限制词` の 5 セクションを出します。明示指定、自動補完、矛盾の調整、成人かつ非露骨な表現範囲を確認し、見どころは 3–5 個です。Director のモード選択は正式には定義されていません。

| Director の `输出模式` | 結果 |
| --- | --- |
| `标准` | 標準。固定パラメータ、読みやすいモジュール解説、最終プロンプト、ネガティブ指定 |
| `简洁` | 最終プロンプトとネガティブ指定のみ |
| `导演详版` | 標準より詳しい場面・撮影設計の説明 |
| `直接生成图片` | 内部でプロンプトを準備し、利用可能な画像機能を実行 |
| `参考图直接生成` | 参照の対象を固定して生成・編集し、画像と短い説明を返す |

標準の最終プロンプトは実質的な 5 段落です。第 1 段落に寸法、人物、成人年齢、顔、メイク、気質、第 2 段落に時間、出来事、動作、視線、第 3 段落に体型、服装、配色、素材、装身具、装飾密度、第 4 段落に環境、空間、カメラ、構図、被写界深度、第 5 段落に光の位置、ハイライト、影、調色、質感を記します。公開解説は採用した視覚表現と効果を説明し、内部の逐次推論は公開しません。

最終プロンプトとネガティブ指定は別々の Markdown `text` コードブロックに入ります。`只要最终提示词` は簡潔モードと同じで、ネガティブ指定も含みます。パラメータだけの入力はテキスト依頼です。画像が必要なら明示的に生成を依頼してください。画像モードでは内部プロンプトを表示しない場合があります。

## 6. コピーして使う例

以下は Codex に渡す依頼文であり、画像生成済みの結果ではありません。角括弧のプレースホルダーは実際の入力に置き換えます。人物は明確に成人とし、テキストのみの場合は架空人物を標準にします。中国語のフィールド名・値はそのまま使い、必要なら日本語の補足を加えてください。

### A. Generator：室内写真の詳細指定

```text
$female-portrait-prompt-generator

人物为虚构的 26 岁成年东亚女性。未填字段自动补全，已填参数保持不变。
写真风格：清冷私房
五官方向：温柔圆脸型
场景方向：窗边
服装方向：白衬衫
服装颜色：米白
气质标签：安静、克制
身形方向：柔和曲线
线条强调：中
身体线条重点：锁骨肩颈
姿态方向：低头安静
镜头方向：半身近景
面部呈现：完整脸部
光线方向：阴天窗光
色调方向：冷灰蓝
精修程度：自然真实
画幅比例：3:4
画质方向：真实摄影
```

5 セクションが返り、優しい丸顔、オフホワイトのシャツ、顔全体、自然な仕上げ、3:4 を保持します。不足した詳細だけを補完します。

### B. Director：都会の場面演出

```text
$female-portrait-director

写真风格：都市时尚写真
年龄特征：28 岁成年东方女性
五官方向：知性长脸型
场景方向：雨后城市街角的咖啡馆外
服装方向：深灰色西装外套、米白色内搭、黑色直筒长裤
配色方向：深灰为主，米白为辅，少量银色点缀
华丽度：低，依靠面料与剪裁体现质感
气质标签：知性、冷静、轻熟
身形方向：自然协调
身形吸引力强度：弱
线条重点：肩颈与整体比例
镜头方向：平视，膝盖以上构图
光线氛围：阴天柔光，少量街边暖光
滤镜效果：低饱和，保留自然肤色
画幅比例：3:4
平台用途：个人作品集
输出模式：标准
补充要求：人物为虚构成年女性；设计自然停步的瞬间，不添加文字
```

標準出力、5 段落の統合プロンプト、独立したネガティブ指定を期待します。立ち止まる動作、視線、衣服、光、雨上がりの環境が同じ一枚として成立するようにします。

```text
场景：有竹影的现代茶室
服装：墨绿色新中式上衣与米白长裙

输出模式：简洁

```

### D. 既存プロンプトの診断と最適化

```text
$female-portrait-director

请先诊断，再优化下面的提示词。
必须保留：温柔圆脸型、墨绿色服装、窗边场景、3:4 画幅。
目前问题：结果变成尖下巴、黑色衣服，背景变成影棚。
请解释可能原因，给出修复后的最终提示词与负面约束。
原提示词：[粘贴原文]
```

元のパラメータや失敗画像があれば添えます。診断では指定の競合、ルート選択、固定項目の欠落、モデルの限界を分け、単に長くすればよいと扱わないことが重要です。

### E. 複数のパラメータ案

```text
$female-portrait-director

请推荐 3 组可直接调用的成年女性写真参数。

每组只选一个主风格，场景与服装颜色不要重复。
统一画幅比例 3:4，不直接生成图片。
```

### F. 画像からプロンプトを作る

先に画像を添付します。観察できる特徴を扱う依頼で、本人の特定や生成画像での本人性保持を意味しません。

```text
$female-portrait-director

请分析上传图片的构图、服装、光线、配色和可观察的外貌特征，
反推可用于虚构成年女性人像的提示词。
不识别或推测真实身份；不能确定的内容标为推断。
只输出最终提示词和负面约束，不生成图片。
```

### G. 架空人物を直接生成

```text
$female-portrait-director

写真风格：旅行假日写真
年龄特征：30 岁成年女性
场景方向：海边酒店阳台
服装方向：浅蓝色棉麻连衣裙
画幅比例：3:4
输出模式：直接生成图片
补充要求：虚构人物，保持自然摄影质感。
```

### H. 許可された人物と衣服を保持

先に 2 枚の画像を添付します。自分ではなく許可を得た成人モデルを使う場合は、説明を事実に合わせて変更してください。

```text
$female-portrait-director

直接生成图片。
图片 1 是我本人，已成年，作为 identity_reference。
图片 2 是有权使用的服装图，作为 product_reference。
写真风格：电商服装模特图
画幅比例：3:4
输出模式：参考图直接生成
保留对象：图片 1 的脸型、眉眼、鼻唇；图片 2 的服装主色、版型、图案、领口结构。
允许改变：发型、姿态、背景与光线。
禁止改变：人物五官身份、服装品类、主色与关键结构。
补充要求：简洁背景、自然站姿、服装完整清楚。
```

## 7. 参照画像の扱い

各画像に `identity_reference`（本人または許可された成人）、`product_reference`（服装・商品）、`style_reference`（表現のみ）、`edit_target`（編集対象の原画像）を指定します。不明な場合は生成前に役割を明確にします。

本人性は標準で顔の形、眉と目、鼻と唇、識別できる特徴を固定します。髪型、体型、姿勢、メイク、構図は自動では固定しません。商品は種類、輪郭、色、素材、柄、主要構造を保持します。より厳密な条件は `保留对象` と `禁止改变` に追加します。

スタイル参照は、その人物を複製する権利や依頼を意味しません。画像からのプロンプト化はテキスト、参照生成は画像を返します。Director は本人性・商品構造の変化を確認し、必要なら一度、対象を絞って再試行します。ロゴ、小さな文字、複雑な模様は完全一致を保証せず、厳密な文字には後から編集や合成が必要な場合があります。

## 8. 問題の切り分けと既知の不整合

| 状況 | 対応 |
| --- | --- |
| 顔や服、色が置き換わる | 元の固定指定を添え、競合する標準語句を整理して診断を依頼 |
| 出力が長い | Director は `简洁`、Generator は短縮した応答を別途指定 |
| パラメータから文字しか返らない | 正常動作。画像には `直接生成图片` を明示 |
| 本人性が変わる | 画像の役割と固定特徴を確認し、変更を簡素化してモデル限界も確認 |
| 比率や寸法が違う | 最終プロンプトと実際の画像ツール設定を両方確認 |
| スキルが認識されない | 完全なディレクトリと入口の配置を確認し、新しい会話を開始 |

次の元文書の不整合は無変更で残し、ここで説明しています。

1. Director の中心手順では標準年齢 20–28 歳、スキーマでは 24–28 歳です。Generator は約 22–28 歳です。年齢を明記してください。
